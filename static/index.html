Scientific Foundations & Quantitative Formulas

Biophysical mechanisms & mathematical definitions

1. Deep Learning Organoid Segmentation (Cellpose cyto3)

Organoid boundaries are segmented using Cellpose Deep Learning (cyto3 model). The neural network predicts spatial vector gradient flows, enabling accurate boundary segmentation of arbitrary non-circular organoid shapes without geometric bias.

2. Organoid Mortality Rate & Dye Viability

Dead organoids exhibit compromised plasma membrane integrity, allowing fluorescent dye to enter the cytoplasm. If internal green dye pixel count \( N_{\text{green}} \ge 1 \) or mean green intensity \( G_{\text{mean}} \ge 35.0 \), the organoid is classified as DEAD (outlined in Red). Otherwise it is classified as LIVE (outlined in Blue).

$$\text{Mortality Rate (\%)} = \left( \frac{N_{\text{dead}}}{N_{\text{total}}} \right) \times 100$$

3. Natural Killer (NK) Cell Red Pixel Quantification

Natural Killer (NK) cells produce diffuse, non-punctate fluorescence signals. Rather than imposing arbitrary discrete object counts, NK cells are quantified by exact red pixel count and field-of-view area percentage in HSV color space:

$$\text{NK Red Coverage (\%)} = \left( \frac{\text{Red Pixels (px)}}{\text{Image Width} \times \text{Image Height}} \right) \times 100$$

4. Objective Morphometric Metrics

  • Circularity: $$\text{Circularity} = \frac{4\pi \times \text{Area}}{\text{Perimeter}^2} \quad (1.0 = \text{perfect circle})$$
  • Contour Roughness: $$\text{Roughness} = \frac{\text{Perimeter}}{\text{Perimeter}_{\min}} \quad \text{where } \text{Perimeter}_{\min} = 2\sqrt{\pi \times \text{Area}}$$
  • Equivalent Diameter: $$\text{Equivalent Diameter} = 2\sqrt{\frac{\text{Area}}{\pi}}$$
